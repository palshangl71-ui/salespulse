
# SalesPulse - Retail Sales Analytics

## Project Overview

SalesPulse is a Python-based retail sales analytics
application developed to analyse retail store performance.

## Project Objectives

- Validate raw sales data.
- Calculate total revenue and AOV.
- Calculate estimated gross profit.
- Identify top five revenue-generating products.
- Identify the product with the highest quantity sold.
- Analyse regional sales performance.
- Generate business insights and recommendations.

## Dataset Information

Original Records: 120
Valid Records: 110
Invalid Records: 10

## Technologies Used

- Python
- Pandas
- VS Code
- Git
- GitHub

## Project Modules

1. validation.py - Data validation
2. revenue.py - Revenue calculations
3. product_analysis.py - Product analysis
4. region_analysis.py - Regional analysis
5. main.py - Main application

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

python src/main.py

## Generated Outputs

- Cleaned dataset
- Invalid records dataset
- Sales analytics report
